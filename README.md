# PfLDH-NAD-BetaSitosterol-MD
Reproducible molecular dynamics simulation and trajectory analysis of the Plasmodium falciparum lactate dehydrogenase–NAD+–beta-sitosterol complex
## Archived Molecular Dynamics Dataset

The original 100 ps unrestrained NPT molecular dynamics simulation of the Plasmodium falciparum lactate dehydrogenase (PfLDH)-NAD+-beta-sitosterol complex is publicly archived on Zenodo.

**Zenodo DOI:** https://doi.org/10.5281/zenodo.24038482

The archive contains the original simulation backup, including trajectory files (.dcd), checkpoint states (.xml), the simulation Python script, and the execution log.

The GitHub repository provides the analysis scripts, numerical CSV results, original PNG figures, simulation methodology, and trajectory analysis findings.

**Citation:** Akoo, B. (2026). PfLDH-NAD+-beta-Sitosterol Molecular Dynamics Simulation: 100 ps Unrestrained NPT Trajectory and Checkpoint Data [Dataset]. Zenodo. https://doi.org/10.5281/zenodo.24038482

**Scientific limitation:** The 100 ps trajectory provides short-timescale structural observations. It does not establish long-term complex stability, binding affinity, or enzyme inhibition. The PBC-corrected beta-sitosterol RMSD remains provisional pending independent validation.
