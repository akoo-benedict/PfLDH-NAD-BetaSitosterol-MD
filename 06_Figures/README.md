Original figures generated from the 100 ps PfLDH-NAD-beta-sitosterol molecular dynamics trajectory analysis.

Figures include protein RMSD, NAD+ RMSD, beta-sitosterol RMSD (original and PBC-corrected), protein-ligand residue contacts, system density, and simulation box volume.

The PBC-corrected beta-sitosterol RMSD is provisional pending independent validation of the reconstruction procedure.
