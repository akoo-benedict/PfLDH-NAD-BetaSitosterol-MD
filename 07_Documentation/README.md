Documentation for the PfLDH-NAD+-beta-sitosterol molecular dynamics project.

This folder contains methodological documentation, simulation settings, analysis procedures, reproducibility notes, and limitations.

The molecular dynamics production trajectory covers 100 ps of unrestrained NPT simulation using OpenMM 8.6 on an NVIDIA RTX A6000 GPU.

Large simulation files, including trajectories and checkpoint states, will be archived separately on Zenodo, with their DOI linked to this GitHub repository.
